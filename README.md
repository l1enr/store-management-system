# store-management-system
Store Management System developed in C++ using Object-Oriented Programming (OOP), Binary Search Tree (BST), Queue, and Stack.

---

## Features

- Add new products
- Delete products
- Search products by ID
- Display products in sorted order
- Purchase products
- Queue customer orders
- Process pending orders
- Undo the last operation
- Low Stock Warning for products with quantity less than or equal to 10

---

## Data Structures Used

- Binary Search Tree (BST)
- Queue
- Stack

---

## Object-Oriented Programming (OOP)

The project follows Object-Oriented Programming principles by dividing the system into multiple classes, each with a specific responsibility.

### Main Classes

- Product
- ProductBST
- OrderQueue
- UndoStack
- StoreSystem
